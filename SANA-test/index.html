规划

Sol-Refiner v2 规划

我们计划按照之前哲哥提议的 2 个方向进行探索：① 追求 4K 60FPS；② 用 RSI 自动探索 hybrid attention 结构。两者是配套的：4K 60FPS 的 token 数大幅增加，hybrid attention 用来控制 attention 的计算量。

方向一24FPS → 4K 60FPS

  1. 数据：收集一批 4K 和高帧率（60FPS）的视频进行训练。训练对直接由原片构造：原片作为目标，空间缩小 + 时间抽帧到 24FPS 作为 draft 输入（图 1a）。
  2. 空间 + 时间联合放大：当前开源社区的 latent upscaler 只支持在空间维度（H×W）放大。我们计划扩展为空间 + 时间（T）联合放大，从 24FPS draft video 直接升到 4K 60FPS（图 1b）。
  3. 计算量：按本页 4K（4096×2304）、同样 5 秒计算，4K 60FPS 的 token 数约是 2K 24FPS 的 6 倍，full attention 的计算量约 40 倍，需要方向二的 hybrid 结构来控制。

方向二RSI for Sol-Refiner v2 训练

  1. Hybrid attention 结构：重点探索 hybrid frame-attn / full-attn 结构，即哪些 block 用 frame attention、哪些保留 full attention；部分 block 也可以用 window attention（局部时空窗口）（图 2）。
  2. 交给 RSI 自动完成：结构的搜索、设计和验收都交给 RSI 自动完成：提出结构 → 训练 → 自动评测 → 验收；不通过就修改结构，进入下一轮（图 3a）。
  3. 验收标准：以全部 full attention 的结构为基准，看 4K 原生像素下的清晰度、60FPS 下的时序稳定（不闪烁、不抖动），以及速度和显存（图 3b）。
对比视频上下两半分别是左右两侧的画面，每侧 2560×1440，5 秒（120 帧，24 fps）。SANA-Refiner 推理：LQ 视频作为 in-context token，从 σ=1 起 30 步 Euler（shift 12，CFG 1），文本只用视频描述。
