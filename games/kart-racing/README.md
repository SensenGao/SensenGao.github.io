# Zoomies GP — Critter Kart Carnival

An arcade kart racer for the browser (three.js r170, ES modules, no build step), with ten original critter racers,
three themed tracks plus a night variant, Grand Prix / Quick Race / Time Trial / Missions, English and 中文.
Play: https://sensengao.github.io/games/kart-racing/

## Playing

Arrows/WASD drive · Space drift (hold while steering, release for a mini-turbo) · E item · C look back · Esc pause · M mute.
Gamepad and on-screen touch controls (phones in landscape) are supported. Settings: music / sound / announcer volume,
mute, graphics quality (auto-detected; dynamic resolution keeps the frame rate up), language, steering assist.

## Dev / test hooks

`window.__game` exposes a deterministic stepping API (`setManual`, `step`, `snapshot`, `renderInfo`, `startSession`).
Query flags: `?seed=N` (deterministic RNG), `?quality=low|medium|high`, `?touch=1` (force touch UI), `?hf` (force the
Hugging Face asset copy on localhost). `dev/` holds the track viewer and racer turnaround pages used during development.

Run locally: `python -m http.server` in this folder and open http://localhost:8000/.
